# 🤖 Multi-Model AI Assistant

Um assistente de IA moderno desenvolvido com **React.js** e **Tailwind CSS**, utilizando a **API da OpenRouter**.  
A aplicação permite interagir com múltiplos modelos de IA em uma única interface, facilitando testes, comparações e exploração de diferentes respostas.

---

## 🚀 Funcionalidades

- 🔄 **Suporte a múltiplos modelos de IA**
- 💬 Interação por texto
- 🖼️ Upload de imagens (para modelos com visão)
- 📄 Upload de arquivos (para modelos compatíveis)
- ⚡ Interface rápida e responsiva
- 🎨 Design moderno com Tailwind CSS
- 🔐 Integração segura com API usando variáveis de ambiente

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** React.js (Vite)
- **Estilização:** Tailwind CSS
- **API:** OpenRouter
- **Ícones:** React Icons
